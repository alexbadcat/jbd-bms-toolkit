## Що це

Перевірений у бою набір інструментів, який виріс із експлуатації **двох паралельних 16S
LiFePO4 паків** (≈150 Аг кожен) на гібридному інверторі **Deye SUN-5K-SG03LP1**, з двома
*різними* поколіннями JBD BMS на одній шині RS485:

| Пак | BMS | Протокол запису |
|-----|-----|-----------------|
| A («стара») | JBD **UP16S010**, адреса 0 | класичні JBD **DD**-кадри (`DD A5/5A … 77`) |
| B («нова») | JBD **UP16S019 rev.2** (LS-прошивка), адреса 1 | **ES-UP Modbus** (`0x78`/`0x79`) — DD-записи мовчки ігноруються |

Усе тут розреверсено, перевірено на живому залізі й працює в продакшені 24/7. У документації
є й наші помилки, щоб вам не довелось їх повторювати.

## Можливості

- **`jbd2mqtt`** — демон: опитує кожен пак (комірки, температури, струм, SOC, біти
  балансування, захисти) → MQTT з **автовиявленням Home Assistant** (пристрої зʼявляються
  самі), спільний LWT + доступність на кожен пак.
- **Слідкувач режиму балансування** — пасивний балансир JBD балансує *або* під зарядом,
  *або* в спокої, але не обидва одночасно. Демон перемикає кожен пак у той режим, який
  корисний саме зараз, з гістерезисом, дебаунсом і обмеженням частоти записів.
- **Метрика «розкид на верху»** — розкид комірок лише на верхньому коліні (≥3.45 В): одне
  число, яке чесно показує, чи пак реально розходиться.
- **`jbd_settings`** — дамп / бекап / запис налаштувань BMS по DD з перевіркою збереження
  (перечит свіжою сесією), калібрування струму (`0xAD-0xAF`), **запис залишку ємності
  (`0xE0`)**, щоб виправити кривий SOC.
- **`esup`** — доступ по ES-UP Modbus до прошивки rev.2: режим балансу, залишок ємності,
  лічильник циклів, **калібрування коефіцієнтів напруги кожної комірки** (міф «вендор
  залочив» виявився просто неправильною адресацією запису — див. документацію).
- **Автоматизації Home Assistant** — сторож перенапруги комірок (зупинка до спрацювання
  OVP у BMS), цикл паузи для балансування, нічний сторож балансу, повільна нічна дотяжка
  до 100 %.
- **Lovelace-картка** — інвертор + 2 BMS з анімацією балансування комірок, селектором
  режимів, вкладками графіків і графіка відключень.
- **Розгортання** — systemd-юніт, udev-правило, Docker/compose, конфіг через `.env`.

## Швидкий старт

```bash
git clone https://github.com/alexbadcat/jbd-bms-toolkit.git /opt/jbd-bms-toolkit
cd /opt/jbd-bms-toolkit
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python3 src/jbd_bms.py            # перше читання — перевірка підключення
cp jbd2mqtt.env.example jbd2mqtt.env && nano jbd2mqtt.env
python3 src/jbd2mqtt.py           # пристрої зʼявляються в Home Assistant
```

➡️ **Повна покрокова інструкція (підключення → сервіс → HA → картка → проблеми):
[docs/installation.uk.md](docs/installation.uk.md)**

## ⚠️ Застереження

Запис у BMS може вимкнути захисти або перетворити плату на цеглину. Спершу бекап
налаштувань, не чіпай пороги захисту, яких не розумієш, перевіряй кожен запис. Усе — на
власний ризик, див. [docs/safety.uk.md](docs/safety.uk.md).
